# QA Checklist — JiraTime

Финальный чек-лист для проверки на реальных Windows 10 и Windows 11 машинах.  
Отметьте каждый пункт перед публикацией релиза. Тест-сессия: минимум 2 машины (Win10 + Win11).

---

## 1. Установка и первый запуск

- [ ] NSIS-инсталлятор запускается без прав администратора → устанавливается в `%LOCALAPPDATA%\Programs\JiraTime`
- [ ] MSI-инсталлятор деплоится через `msiexec /i JiraTime.msi /quiet` без ошибок
- [ ] **SmartScreen**: при первом запуске показывает предупреждение → нажать «Подробнее» → «Выполнить» → приложение открывается
- [ ] **WebView2**: если Runtime не установлен — инсталлятор скачивает Evergreen Bootstrapper или применяет офлайн-фоллбэк из MSI
- [ ] При первом запуске сразу открывается онбординг (не главный экран)
- [ ] Повторный запуск после онбординга → онбординг не показывается

---

## 2. Онбординг

- [ ] **Шаг 1 — Jira**: поле URL принимает `https://...atlassian.net` и `https://jira.corp.ru`; кнопка «Проверить соединение» → успех/ошибка с понятным текстом
- [ ] **Шаг 1**: при неверном токене — показывается сообщение об ошибке, не падение
- [ ] **Шаг 2 — Exchange**: кнопка «Пропустить» работает → переход на шаг 3
- [ ] **Шаг 2**: OAuth2 flow открывает браузер → авторизация → callback возвращает в приложение
- [ ] **Шаг 3 — Расписание**: выбор рабочих дней (чекбоксы), часов, часового пояса сохраняется в БД
- [ ] **Шаг 4 — Тур**: все 4 слайда пролистываются, кнопка «Начать работу 🚀» открывает дашборд
- [ ] Переход между шагами анимирован (slide), нет артефактов при быстром клике

---

## 3. CRUD Worklog

- [ ] **Create**: через мастер массового трекинга создать 5+ записей за разные дни → записи появляются в таблице и в Jira
- [ ] **Read**: таблица «Мой журнал» загружает записи с пагинацией; отображаются issue-ключ, дата, часы, комментарий
- [ ] **Update (inline)**: двойной клик на ячейку часов → поле редактирования → `Enter` сохраняет → Jira обновлена; `Esc` отменяет без сохранения
- [ ] **Delete**: кнопка удаления записи → подтверждение → запись удалена из таблицы и из Jira
- [ ] Offline: отключить сеть → попытка создать запись → запись попадает в очередь → включить сеть → запись синхронизируется автоматически

---

## 4. Мастер массового трекинга — граничные случаи

- [ ] **0 рабочих дней в периоде**: период из выходных (например, сб–вс) → мастер показывает предупреждение «Нет рабочих дней в выбранном периоде», кнопка «Залогировать» недоступна
- [ ] **Праздники полностью перекрывают период**: период 1–8 января (новогодние) → все дни исключены → то же предупреждение, что выше
- [ ] **Задача без прав на логирование**: ввести issue-ключ задачи, на которую у пользователя нет права `Work On Issues` → API возвращает 403 → пользователь видит ошибку «Нет прав на логирование» рядом с задачей, остальные задачи логируются штатно
- [ ] **Очень длинный период** (3 месяца) → мастер отображает список дней без зависания UI, прокрутка плавная
- [ ] **Дублирующий worklog**: создать запись за день, где уже есть 8 ч → показывается предупреждение о переработке (не блокирует сохранение, если пользователь подтверждает)

---

## 5. Часовые пояса и DST

- [ ] Создать worklog в период перехода на летнее время (последнее воскресенье марта): `started` в Jira должен содержать корректный offset (`+03:00`), не `+02:00`
- [ ] То же для перехода на зимнее время (последнее воскресенье октября): `started` = `...+03:00`
- [ ] Смена часового пояса в настройках → пересчёт `started` в новых worklog-записях → проверить в Jira через API
- [ ] На машине с UTC+5 (Екатеринбург) `started` корректно отражает локальное время (`+05:00`)
- [ ] На машине с UTC±0 (если есть) `started` содержит `Z` или `+00:00`

---

## 6. Горячие клавиши

- [ ] `Ctrl+N` → открывает мастер массового трекинга с любого экрана
- [ ] `Ctrl+L` → переходит на «Мой журнал» с любого экрана
- [ ] `Ctrl+M` → сворачивает в системный трей; иконка трея видна
- [ ] `Enter` в inline-редакторе → сохраняет (не сабмитит форму дважды)
- [ ] `Esc` в inline-редакторе → отменяет без сохранения
- [ ] `Esc` вне инпута → генерирует `jiratime:close-active-dialog` → закрывает открытый диалог/панель

---

## 7. Темы и визуал

- [ ] Светлая тема: фон, текст, карточки без артефактов; читаемость всего текста (проверить мелкий текст 12px)
- [ ] Тёмная тема: то же самое; heatmap-цвета видны на тёмном фоне
- [ ] Переключение темы: мгновенное, без перезагрузки, без мерцания
- [ ] Системная тема Windows «Тёмная» → приложение стартует сразу в тёмном режиме
- [ ] **DPI 125%**: окно 900×600 — все элементы помещаются, нет обрезаний
- [ ] **DPI 150%**: шрифты крупнее, лейауты не сломаны, таблица читаема
- [ ] **DPI 200%**: проверить бокс-модель, радиусы, иконки — нет пикселизации
- [ ] Минимальный размер окна 900×600: попытка уменьшить ниже → окно не уменьшается или показывает scrollbar

---

## 8. Системный трей и автозапуск

- [ ] Сворачивание в трей (`Ctrl+M` или крестик при включённой опции): иконка появляется в трее, окно исчезает с таскбара
- [ ] Клик по иконке трея → окно разворачивается
- [ ] Правый клик по трею → контекстное меню с «Залогировать сегодня» и «Выход»
- [ ] «Залогировать сегодня» → открывается мастер с сегодняшней датой
- [ ] «Выход» → приложение закрывается, иконка трея пропадает
- [ ] Автозапуск **включён**: перезагрузить Windows → JiraTime запускается в трее без интерактивного входа
- [ ] Автозапуск **выключен**: перезагрузить Windows → JiraTime не запускается
- [ ] Автозапуск использует `HKCU\...\Run` (проверить `regedit` / `msconfig`) — не требует прав администратора

---

## 9. UAC и ограниченные права

- [ ] Обычный пользователь без прав администратора: приложение запускается, все функции работают
- [ ] Обновление через `tauri-plugin-updater`: устанавливается без UAC-запроса (путь `%LOCALAPPDATA%`)
- [ ] Запуск от имени администратора (`Run as administrator`): приложение работает, трей и хоткеи функционируют
- [ ] Корпоративная политика AppLocker/Software Restriction: если `%LOCALAPPDATA%` разрешён — приложение запускается; задокументировать исключение для блокированных сред

---

## 10. Автообновление

- [ ] При запуске приложение через 5 секунд проверяет `latest.json` на GitHub Releases
- [ ] Если обновление доступно — показывается тост/диалог с предложением обновиться
- [ ] Нажать «Обновить» → скачивается `.nsis.zip`, проверяется подпись, применяется обновление, приложение перезапускается
- [ ] После обновления версия в About/заголовке изменилась
- [ ] Если GitHub Releases недоступен (нет сети) → ошибка тихая, нет краша и стека в UI
- [ ] Подпись обновления (`TAURI_SIGNING_PRIVATE_KEY`) невалидна → обновление отклонено с ошибкой

---

## 11. Аналитический дашборд

- [ ] Диаграмма часов по дням за текущую неделю отображается корректно (план vs факт)
- [ ] Переключение «Текущая / Прошлая неделя» работает, данные меняются
- [ ] Donut/stacked bar по задачам за выбранный период: выбрать 3 разных периода, данные обновляются
- [ ] Heatmap за 3 месяца: дни без worklog — серые, дни с полным заполнением — тёмно-зелёные
- [ ] Список дней с «дырками»: клик «Залогировать» открывает мастер на нужную дату
- [ ] Метрика экономии времени: после нескольких bulk-сессий счётчик растёт
- [ ] Графики без артефактов при переключении тёмная/светлая тема
- [ ] Ресайз окна → графики перерисовываются без overflow
