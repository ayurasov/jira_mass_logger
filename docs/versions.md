# История версий

Что нового в JiraTime — простым языком. Здесь только последние версии; полный технический список изменений — в CHANGELOG.md.

## Версия 1.0.17 (Ноябрь 2026 г.)

Календарь Exchange с входом по NTLM снова подключается: в 1.0.16 он перестал работать из-за ускорения обмена с Jira.

### Исправлено

- подключение к Exchange (EWS) с входом по NTLM снова проходит; раньше оно останавливалось на ошибке «NTLM: сетевой запрос Type1», даже при верном пароле;
- в ошибках подключения к календарю теперь видна сама причина, а не только шаг, на котором произошёл сбой;
- ускорения обмена с Jira из 1.0.16 остались в силе.

## Версия 1.0.16 (Октябрь 2026 г.)

Обмен с Jira стал быстрее и легче: меньше запросов, меньше трафика и меньше нагрузки на сервер — без ограничений, всё обновляется как раньше, только быстрее.

### Быстрее

- соединение с Jira устанавливается один раз и переиспользуется — экраны больше не ждут нового подключения при каждом обращении;
- ответы Jira приходят сжатыми — данных по сети передаётся в несколько раз меньше;
- записи по задачам приходят вместе с поиском; отдельно догружаются только задачи с большой историей — параллельно и только за нужный период;
- названия задач при синхронизации «Моего worklog» подтягиваются одним запросом, а не по одному на задачу;
- текущий пользователь Jira и токен запоминаются на время работы — не запрашиваются заново перед каждой загрузкой.

### Бережнее к серверу

- автоматическое обновление «Моего worklog» смотрит только задачи, изменённые с прошлого раза, а не весь период;
- одинаковые обновления, запущенные одновременно, объединяются в одно;
- проверка связи не отправляет лишний запрос, если Jira только что отвечала.

## Версия 1.0.15 (Октябрь 2026 г.)

Боковое меню стало уже и спокойнее: без подписей горячих клавиш у каждого пункта, «Руководство» внизу, рядом — копирайт и эта история версий.

### Интерфейс

- боковое меню стало уже — экранам достаётся больше места; значки разделов приглушены, текущий раздел выделен цветом;
- в боковом меню больше нет подписей горячих клавиш у пунктов — сами клавиши работают как раньше и видны во всплывающей подсказке;
- «Руководство» перенесено в низ меню, туда же — кнопка «О программе»;
- внизу меню — копирайт и номер версии: щелчок по нему открывает это окно с историей версий.

## Версия 1.0.14 (Октябрь 2026 г.)

Руководство пользователя теперь открывается прямо в приложении, а «Собрать день» аккуратнее добавляет задачи и предлагает только те, которые вы выбрали.

### Руководство в приложении

- пункт «Руководство» в боковом меню открывает руководство на главе того экрана, с которого вы пришли;
- поиск по всему руководству с подсветкой найденного, ссылки между главами и кнопка «Открыть экран»;
- рисунки открываются крупно по щелчку; руководство работает без интернета и обновляется вместе с приложением.

### «Собрать день»

- задача, добавленная из «Привычных задач», встаёт в своё привычное время или в ближайшее свободное окно рабочего дня — раньше она уезжала за конец дня;
- если задача целиком не помещается, она встаёт в самое длинное свободное окно и не занимает больше, чем осталось до нормы — встречи из-за неё больше не пропадают;
- у каждой привычной задачи — галочка «в предложении»: без неё задача не подставляется сама, но её можно добавить вручную; выбор запоминается и переносится вместе с настройками.
